# FeetForTarantino — Movie Watchlist Telegram Bot

Телеграм бот для группового управления вотчлистом фильмов. Поиск через TMDB, голосование, умные рекомендации через MCP сервер.

## Быстрый старт

```bash
# 1. Создай .env файл
cp .env.example .env  # заполни токены

# 2. Создай базу данных
createdb movie_bot

# 3. Запусти
./run.sh
```

## Переменные окружения (`.env`)

```env
TELEGRAM_BOT_TOKEN=...   # от @BotFather
TMDB_API_KEY=...          # от themoviedb.org
DATABASE_URL=postgresql://user@localhost:5432/movie_bot
```

## Структура

```
movie_watchlist_bot.py  — основной бот
tmdb_mcp_server.py      — MCP сервер для умных рекомендаций
run.sh                  — скрипт запуска
requirements.txt        — зависимости
.env                    — секреты (не в git)
```

## Команды

### Основные
| команда | описание |
|---------|----------|
| `/add название` | добавить фильм с поиском TMDB |
| `/add` + список строк | пакетное добавление без TMDB |
| `/list` | список к просмотру (пагинация, кнопки) |
| `/list -s Matrix` | поиск по названию |
| `/list -ps 25` | размер страницы |
| `/wlist` | просмотренные фильмы |
| `/info 5` | детали фильма #5 |
| `/watched 5` | отметить #5 просмотренным |
| `/remove 5` | удалить #5 |
| `/rename 5 Название` | переименовать |

### Рандом и голосование
| команда | описание |
|---------|----------|
| `/random` | случайный фильм |
| `/poll N` | Telegram poll из N случайных |
| `/vote 1,5,12` | poll из выбранных номеров |
| `/rpoll 1,5,12` | рандом из выбранных |

### Корзина голосования
| команда | описание |
|---------|----------|
| `/v+ 1,5,12` | добавить в свою корзину |
| `/v-` | очистить свою корзину |
| `/vmy` | посмотреть свою корзину |
| `/vlist` | общая корзина всех |
| `/go` | запустить poll из корзины |
| `/vrand` | рандом из корзины |
| `/vc` | очистить всю корзину |

### Рекомендации (MCP)
| команда | описание |
|---------|----------|
| `/suggest` | рекомендации по истории просмотров |
| `/suggest мрачное` | рекомендации по настроению |
| `/suggest мрачное но короткое` | с уточнением |
| `/similar Inception` | похожие на фильм (без уже добавленных) |

### Утилиты
| команда | описание |
|---------|----------|
| `/sync` | синхронизировать данные с TMDB |
| `/sync 5` | синхронизировать фильм #5 |
| `/sync -a` | синхронизировать все |
| `/export` | экспорт в .txt |
| `/export -csv` | экспорт в .csv |
